# Site institucional da Nexora — nexora.ia.br

Site estático (HTML + CSS puro, sem build) publicado pelo GitHub Pages a partir da branch `main`.

- `index.html` — one-page institucional
- `privacidade/` — Política de Privacidade (LGPD)
- `termos/` — Termos de Uso
- `assets/` — CSS, símbolo da marca, favicons e imagem Open Graph
- `CNAME` — domínio custom do GitHub Pages (`nexora.ia.br`)

Publicar = fazer `git push` na `main`. Não há dependências nem etapa de build.
